Pengalaman & impak

Kerja pentadbiran yang teliti, disokong pemikiran teknikal.

Tugas harian saya menghubungkan manusia, jadual dan maklumat. Saya memastikan dokumen, rekod operasi dan laporan bulanan sentiasa teratur, sambil menyelaras pengisian kuliah untuk komuniti masjid.

Apabila proses manual mula mengambil masa, saya cuba memahami puncanya dan membina penyelesaian sendiri—daripada penjana jadual kuliah hingga automasi menggunakan Python, n8n dan cron.

  • 01

    Dokumentasi & laporan

    Menyediakan rekod operasi dan laporan bulanan untuk dihantar ke pejabat zon.

  • 02

    Penyelarasan program

    Mengurus jadual dan rotasi 20 penceramah bagi kuliah serta tazkirah.

  • 03

    Penambahbaikan proses

    Meneroka automasi dan aplikasi web untuk mengurangkan kerja berulang.

01 / Produk komuniti

PoGo Wave Radar

Penjejak acara Pokémon GO merentas zon waktu yang menunjukkan acara aktif, bandar pilihan dan koordinat yang boleh disalin.

  • Data acara dikemas kini setiap 30 minit melalui GitHub Actions.
  • Menyokong 19 bandar utama dan pemasangan pada skrin utama telefon.
  • Antara muka dwibahasa Bahasa Melayu dan English.

Python · GitHub Actions · PWA · GitHub Pages

02 / Aplikasi peribadi

Auto Service Tracker

PWA untuk merekod servis kereta dan motosikal, mengira servis seterusnya berdasarkan jarak atau tempoh, dan menyegerakkan data antara peranti.

  • Menyokong pelbagai kenderaan dan jadual penyelenggaraan tersuai.
  • Status berwarna untuk servis normal, hampir tiba dan terlewat.
  • Data setiap pengguna diasingkan melalui Firebase Authentication dan Firestore rules.

Vanilla JavaScript · Firebase · Service Worker · PWA
