    masjid talhah · preview

    Website Masjid Talhah Laman rasmi masjid: waktu solat, kuliah terdekat, jadual bulanan, galeri dan sumbangan. Next.js, Sanity dan Supabase, dengan admin berlapis TOTP.

  2. kengkorok.github.io/pallet-office

    Pallet Office Ofis pixel di mana setiap session Claude Code jadi Pokémon: kerja di meja, panggil helper untuk subagent, dan lari ke Pusat Pokémon bila perlukan aku. Demo ni replay hari kerja olok-olok.

  3. kengkorok.github.io/pogo-wave-radar

    PoGo Wave Radar Event Pokémon GO bergerak macam ombak ikut zon waktu. Pilih bandar, salin koordinat, kejar event. Data dikemas kini automatik setiap 30 minit.

    Buka ↗
  4. jadual-kuliah-generator.html

    Jadual Kuliah Generator Ganti PSD 264 layer dengan satu fail HTML. Tetapkan aturan kuliah berulang, klik petak untuk sunting, eksport poster A3 300 dpi.

    Cuba ↗ Kod

  5. Servis Tracker PWA jejak servis kereta dan motor: minyak hitam, coolant, roadtax dan lesen. Login Google, data ikut akaun, hos percuma atas GitHub Pages.

    Buka ↗
